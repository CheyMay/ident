Code9 IDENT Admin 1.0
=======================

Версия сборки: 1.0.1

Установка
---------

1. Распакуйте архив на своем компьютере.
2. Запустите 1-INSTALL-ADMIN.cmd.
3. Оставьте адрес https://ident.code9dev.ru и введите SERVICE_API_KEY сервера.
4. На рабочем столе появится ярлык Code9 IDENT Admin.

Важно: SERVICE_API_KEY — это отдельный ключ администратора. Ключ агента клиники
для установки админского приложения не подходит.

SERVICE_API_KEY хранится в зашифрованном хранилище Windows DPAPI и доступен только
текущему пользователю на этом компьютере. В ZIP ключей и настроек нет.

В приложении доступны состояние агентов, расписание, структура базы IDENT,
удаленная настройка SELECT-запросов, переключатели выгрузки/робота и управляемые
обновления клиентского агента.

Публикация версии не обновляет клиники автоматически. После публикации выберите
версию и конкретный агент, затем нажмите "Назначить версию".
