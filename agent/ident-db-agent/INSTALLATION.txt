УСТАНОВКА CODE9 IDENT
=====================

В архиве два файла:

1-УСТАНОВИТЬ.cmd   - единственный файл, который нужно запустить.
2-ИНСТРУКЦИЯ.txt   - эта инструкция.

Перед установкой
----------------

1. Полностью распакуйте ZIP в обычную папку.
2. Откройте IDENT на компьютере клиники.
3. Подготовьте пароль SQL-пользователя readonly_user и ключ агента Code9.

Установка
---------

1. Дважды нажмите 1-УСТАНОВИТЬ.cmd.
2. Agent ID оставьте предложенным.
3. Адрес SQL Server обычно: 192.168.0.3
4. SQL login: readonly_user
5. Введите пароль SQL-пользователя.
6. Адрес Code9 оставьте: https://ident.code9dev.ru
7. Введите ключ агента Code9.
8. Дождитесь сообщения о завершении установки.

После установки
---------------

В области уведомлений Windows появится Code9 IDENT. Программа будет запускаться
автоматически при входе в Windows. Двойное нажатие по значку открывает состояние
связи, базы и расписания.

Пароль SQL и ключ агента шифруются средствами Windows и не отправляются в лог.
Робот заявок после установки выключен.

Первичная проверка робота
------------------------

1. Оставьте переключатель робота выключенным.
2. Разверните календарь IDENT. В Code9 IDENT нажмите «Проверить окно IDENT».
3. Подождите не больше минуты. Появится сообщение о сохранении снимка окна.
4. В IDENT откройте меню свободного времени «Записать на прием» и повторите проверку.
5. Откройте «Новый прием» и повторите проверку еще раз. Пока не сохраняйте прием.
6. Кнопка «Открыть папку» ведет к папке robot с результатами проверок.

Проверка ничего не вводит и не сохраняет в IDENT. Она не включает робота.
Снимки нужны специалисту для проверки полного пути записи. По одним скриншотам
невозможно гарантировать, что робот правильно распознает поля именно вашей версии.
Не включайте очередь до контрольного приема, проверенного в самом IDENT.

Контрольный прием со специалистом
--------------------------------

Выберите согласованного тестового пациента и свободный интервал на 45 минут.
После запуска не трогайте мышь и клавиатуру: робот ждет минуту бездействия.
Проверьте в IDENT ФИО, телефон, врача, дату, начало, конец и комментарий.
Прием должен быть ровно один; после выгрузки все его интервалы должны быть
заняты в amoCRM. Затем проверьте длительность 2 часа без пересечения чужих записей.

Если написано «нужна проверка результата», не создавайте дубликат и не очищайте
файлы робота. Сначала проверьте IDENT. Расписание продолжает выгружаться независимо
от приостановки робота. Для срочной записи используйте обычный ручной ввод в IDENT.
