УСТАНОВКА CODE9 IDENT
=====================

В архиве два файла:

1-УСТАНОВИТЬ.cmd   - единственный файл, который нужно запустить.
2-ИНСТРУКЦИЯ.txt   - эта инструкция.

Перед установкой
----------------

1. Полностью распакуйте ZIP в обычную папку.
2. Откройте IDENT на компьютере клиники.
3. Подготовьте пароль SQL-пользователя readonly_user и ключ агента Code9.

Установка
---------

1. Дважды нажмите 1-УСТАНОВИТЬ.cmd.
2. Agent ID оставьте предложенным.
3. Адрес SQL Server обычно: 192.168.0.3
4. SQL login: readonly_user
5. Введите пароль SQL-пользователя.
6. Адрес Code9 оставьте: https://ident.code9dev.ru
7. Введите ключ агента Code9.
8. Дождитесь сообщения о завершении установки.

После установки
---------------

В области уведомлений Windows появится Code9 IDENT. Программа будет запускаться
автоматически при входе в Windows. Двойное нажатие по значку открывает состояние
связи, базы и расписания.

Пароль SQL и ключ агента шифруются средствами Windows и не отправляются в лог.
Робот заявок после установки выключен.

Первое включение робота
-----------------------

1. Разверните IDENT и откройте пустое окно «Новый прием».
2. Откройте ярлык «Code9 IDENT» на рабочем столе.
3. Нажмите «Настроить и включить робота».
4. Ничего не вводите и не закрывайте около минуты.
5. Готовый результат: зеленое состояние службы и текст «Робот включен».

Если приложение просит повторить настройку, запись не выполнялась и заявка не
потеряна. Разверните именно окно «Новый прием» и нажмите кнопку еще раз.
